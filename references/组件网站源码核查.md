## 如何使用这份核查

- 已逐项尝试读取网页：直接 HTTP 30条返回200，Rare UI 返回429，但其正文通过网页工具可读。工具报403/提取失败与站点完全不可访问分开记录。
- “已取得源码”表示实际读取了下表链接指向的源文件，不表示所有依赖齐全、已运行或所有 Pro 内容免费。
- 取得源码和获得复制许可分别判断。不能复制未授权收费项；只能用法片段或灵感案例时，继续从其他书签找真正可复用的组件。
- 两次 Chrome 页面操作超时，停止重复操作；没有把未完成的 Copy、导出或交互检查写成已完成。
- 网站源码和许可会变化：以后制作组件时，按类型挑候选、重看具体演示与当前条款，再复制完整必要文件，不必每次重查全部31条。

## 后续检索优先级

- 边界光束、思考球、粘液和液态金属：先查 Libraries.dev 对应包。
- 过渡/变形：先查 Transitions.dev；作品集轮播先查 Viscose Carousel。
- 文字和背景效果：先查 React Bits；基础结构查 shadcn/ui；复杂区块查 ObsidianUI。
- 视频宣传片才用 Remocn；不把视频模板流程强塞进普通页面。
- Vault、Beautiful UI、Bencho、Amicro、Rare UI、MetalForge 保留为候选：拿到实际源码/导出并核对许可后才能记为已复用。
