# 反套路清单（AI 生成感 / 行业平均值）

用途：
- 步骤4：给第1～3版写“套路清单”时，从这里点名。
- 步骤5：每个发散版至少避开其中 2 条，并写明避开了哪几条。
- 评审：与unslop适配审查法同次使用，只定位有证据的可见问题，不额外增加审查轮次。用户参考与既有设计系统优先。

例外：某条套路在本项目里确实是最优解（例如工具类产品用卡片列表），可以保留，但必须写一句理由。没有理由的保留按“未避开”计。

## A. Anthropic《frontend-design》SKILL.md 点名的问题

来源（2026-10-18 全文读取）：https://raw.githubusercontent.com/anthropics/skills/main/skills/frontend-design/SKILL.md

AI 设计扎堆的五种外观：
- [ ] A1 米色底（约 #F4F1EA）+ 衬线标题 + 陶土色强调（约 #D97757）
- [ ] A2 近黑底 + 单一酸绿或朱红强调
- [ ] A3 报纸式细分隔线 + 零圆角，硬凹“编辑感”
- [ ] A4 全站同一圆角、同一灰阴影（rgba(0,0,0,.1)）的 SaaS 卡片，加装饰性渐变
- [ ] A5 模板化元素：全大写眉标、“A · B · C”、“WORD — fragment”、用 #0B0B0B 代替纯黑、等宽小标签、按钮文字后加“→”

“生成感”标志：
- [ ] A6 标题里只给一个词加颜色或斜体强调
- [ ] A7 标签全部大写
- [ ] A8 内容上方多余的眉标（eyebrow）
- [ ] A9 内容不是序列，却编号 01 / 02 / 03
- [ ] A10 每个区块都淡入上滑
- [ ] A11 每张卡片都有 hover 效果
- [ ] A12 首屏“大数字 + 小标签 + 渐变点缀”

该文件给出的做法：
- 风格从题材本身的行业、材料、行话里来，全程使用真实内容。
- 先写令牌方案（4～6 个命名颜色、字体角色、ASCII 线框、对齐方式、设计原则），再对照 brief 自查：凡是“对任何类似页面都会这么做”的部分都要改。
- 只在一个地方大胆，其余克制；“出门前摘掉一件配饰”。

## B. OpenAI《Frontend prompt instructions》点名的问题

来源（2026-10-18 全文读取）：https://developers.openai.com/api/docs/guides/frontend-prompt.md

- [ ] B1 卡片套卡片；页面区块做成浮动卡片
- [ ] B2 卡片圆角大于 8px（该文件的上限）
- [ ] B3 装饰性光球、bokeh 光斑、渐变光球
- [ ] B4 左右分栏卡片式 hero；用渐变或 SVG 拼出的 hero（该文件要求满版位图，文字不放进卡片）
- [ ] B5 首屏完全封闭，看不到下一段内容的边缘
- [ ] B6 单一色相主导：紫 / 紫蓝渐变、米 / 沙色、深蓝 / 板岩、棕 / 橙 / 浓缩咖啡色
- [ ] B7 文字溢出、重叠，或布局因内容加载跳动（应使用 aspect-ratio、网格轨道、min/max 固定尺寸）

注意两处与其他来源的冲突：
- OpenAI 要求“字号不随视口缩放、字间距为 0”，与 Utopia 流体字号相反。本技能的取舍：营销/编辑类页面可用 clamp 流体字号（保证 rem 下限）；工具类界面用固定档位。
- OpenAI 的 GPT-5 Cookbook 推荐 Tailwind + shadcn + Inter/Geist 作为默认栈（https://developers.openai.com/cookbook/examples/gpt-5/gpt-5_frontend）。默认栈本身就容易产生同质化外观：用这些工具可以，但不得直接用它们的默认字体、默认圆角和默认配色。

## D. 趋势使用前的五问（Smashing Magazine，2026-07）

来源：https://www.smashingmagazine.com/2026/07/designing-distressed-users-mental-health-apps-ui/

引入任何趋势（新粗野主义、隐藏导航、无标签图标、玻璃拟态、游戏化等）前回答：
1. 认知负荷：会不会增加用户的思考量？
2. 情绪匹配：这个外观符合用户此刻的情绪吗？
3. 导航可预期：用户还能猜到东西在哪吗？
4. 可访问性：对比度、焦点、动效降级还成立吗？
5. 参与方式：有没有胁迫用户参与（不可跳过的动画、强制游戏化）？

任何一问答“会伤害”，就不用这个趋势，或者只在不影响主流程的位置用。

## M. 动效与交互的老套和 AI 味（详见 `references/交互动效.md` D 节）

另一类失败是**完全不动**：没有按压、没有 hover、没有过渡，页面像静态截图。这一条和下面的老套动效同等严重。

- [ ] M0 页面死板：可按元素没有按压反馈、弹层没有进出场、页面切换硬跳
- [ ] M1 从 `scale(0)` 弹出；UI 用 ease-in；全站 `transition: all`（Emil Kowalski 检查表）
- [ ] M2 自动轮播 Hero；滚动劫持；大面积视差背景（NN/g）
- [ ] M3 animate.css 式 bounceIn、到处 overshoot 弹跳
- [ ] M4 慢悠悠的转圈 loader、全屏 loading 遮罩
- [ ] M5 无限循环的抖动或脉冲 CTA
- [ ] M6 鼠标拖尾彩色粒子；自定义光标完全替代原生光标且在触屏上也启用
- [ ] M7 高频操作（每天几十次以上）加了装饰动画；键盘操作加动画
- [ ] M8 UI 动画超过 300ms 且不是大面积转场；进场和退场一样长
