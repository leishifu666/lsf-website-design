## F. 原生交互与内容状态（2026-10-19 补充）

本节按问题选用，不要求每个页面全部使用。API 已按所附官方资料核对；【归纳】为设计建议。实施时保留可读、可操作的基础方案，未在目标环境测试的行为不写成通过，不因新能力升级依赖或扩大任务范围。

### F.1 移动 iframe 时保留状态

**问题 / 做法**：传统移除再插入可能重建 iframe；moveBefore 的状态保留移动可避免这种重建。它不能补救框架重新挂载，先保持原节点与业务身份。

```js
// 前提：同一 document、连接状态一致，slot 不是 player 的后代。
if (typeof slot.moveBefore === "function") slot.moveBefore(player, null);
else slot.insertBefore(player, null);
```

**限制 / 验证**：当前 MDN 标为有限支持；不同文档、连接状态不一致或无效父子关系会失败。insertBefore 降级仅保证移动，不保证保留 iframe 播放状态；必要时保留播放器原位、改变周围布局。不把此问题泛化成原生 audio/video 每次移动都重播。[MDN moveBefore](https://developer.mozilla.org/en-US/docs/Web/API/Element/moveBefore)。2026-10-19 在本机 Chrome 155 的 srcdoc 夹具中，moveBefore 保留文档随机标识和已编辑输入，appendChild 对照发生重载；这不等于已测真实播放器，实施后仍要测媒体、焦点与嵌入服务行为。

### F.2 可搜索折叠与展开动画

**问题 / 做法**：需要被浏览器查找的 FAQ 等内容先保留在 DOM；适合时用 `hidden="until-found"`。查找或片段导航命中后，浏览器触发 beforematch 并移除 hidden；组件同步展开状态、aria-expanded 和框架状态，避免渲染后重新关闭。

**限制**：未渲染、祖先 display:none 或不兼容的 display/containment 会阻止揭示；until-found 仍可能保留盒子的背景、边框和间距。不要留无法解除的 aria-hidden 或 inert。旧浏览器核对查找行为，必要时默认展开或提供“展开全部”，不宣称全平台一致。

**展开动画【归纳】**：问题不是 height:auto 本身，而是普通数值插值无法直接过渡到固有尺寸。grid 轨道 0fr → 1fr 是一种替代，内层需允许收缩并裁切：

```css
.collapse { display: grid; grid-template-rows: 0fr; }
.collapse[data-open="true"] { grid-template-rows: 1fr; }
.collapse__inner { min-block-size: 0; overflow: hidden; }
@media (prefers-reduced-motion: no-preference) {
  .collapse { transition: grid-template-rows 260ms ease; }
}
```

代码仅处理视觉：0fr 不会自动把链接移出 Tab 序列。与 until-found 同用时，beforematch 还要解除外层 0fr 裁切和交互限制。支持时可局部增强为 interpolate-size: allow-keywords，不把实验性能力设置到全站根节点后假定无副作用。

**来源 / 检查**：[MDN hidden](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/hidden)、[grid-template-rows](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/grid-template-rows)、[interpolate-size](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/interpolate-size)。2026-10-19 本机 Chrome 155 夹具验证了片段导航揭示内容并通过 beforematch 同步 aria-expanded，及 grid 关闭高度为 0、打开后恢复内容高度；未操作浏览器查找 UI，也未验证完整键盘语义。项目中再测 Ctrl/⌘F、关闭面板内的 Tab 和快速反向操作；grid 动画仍会计算布局，不保证零开销。

### F.3 模态框的滚动条与滚动链

**问题 / 做法**：锁滚动使经典滚动条消失导致横移时，在实际根滚动容器预留空间；面板滚动到头后传给背景时，在面板滚动容器限制滚动链。

```css
html { scrollbar-gutter: stable; }
.modal__scroll {
  max-block-size: 80dvh;
  overflow: auto;
  overscroll-behavior: contain;
}
```

**限制 / 验证**：覆盖式滚动条不占空间，stable 不会为其强制造占位。检查库是否已做 padding 补偿，避免双重补偿；横移量不固定为 15px。contain 管滚动链，不等于完整锁背景、焦点约束或模态语义。测试开关位置、触顶触底、触屏和键盘滚动。

**来源**：[MDN scrollbar-gutter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/scrollbar-gutter)、[overscroll-behavior](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/overscroll-behavior)。背景景深选项见 [交互动效 I.7](../../交互动效.md)。

### F.4 tooltip 随实际备用位置改变方向

**问题 / 做法**：只有配置了锚点定位与备用位置，浏览器才会尝试翻转；不是任何 tooltip 都自动避让。锚定容器查询需要 container-type: anchored，并且只能改变其后代，不能直接改变查询容器本身。

```css
.tooltip {
  position: fixed;
  position-anchor: --trigger;
  position-area: top;
  position-try-fallbacks: flip-block;
  container-type: anchored;
}
.tooltip__surface { transform-origin: bottom center; }
@container anchored(fallback: flip-block) {
  .tooltip__surface { transform-origin: top center; }
}
```

触发器另设 anchor-name: --trigger，多实例隔离锚名。动画与箭头放到 surface 等子层；上例只展示位置相关样式，不是完整 tooltip。查询能力按目标浏览器检测并渐进增强，不支持时用现有定位库的 placement 或静态提示。保留键盘 focus 与 hover 信息，测试四边溢出、嵌套滚动和多实例。[MDN anchored container queries](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Anchor_positioning/Anchored_container_queries)。

### F.5 输入区随内容增长

**适用 / 做法**：短消息与较短表单可用 field-sizing: content 减少过早的嵌套滚动，同时保留最大高度和手动调整。

```css
textarea {
  inline-size: 100%;
  min-block-size: 3lh;
  max-block-size: 12lh;
  overflow: auto;
  resize: vertical;
}
@supports (field-sizing: content) {
  textarea { field-sizing: content; }
}
```

**限制 / 验证**：当前 MDN 为 2026-06 新近可用；旧浏览器保留原生 textarea。不要用固定高度阻止增长。测试空值、placeholder、长文粘贴、中文输入法、缩放和达到最大高度后的滚动；不为普通表单强制加 JS 测高。[MDN field-sizing](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/field-sizing)。

### F.6 组件尺度与圆角【归纳】

需要相同柔和度的系统可按组件尺寸建立圆角阶梯，或从外层圆角减去间距推导嵌套圆角，避免所有大小统一同一数值。12 / 16 / 24px 是用户示例，不是按钮、卡片、模态框的固定对应。

沿用品牌和已有令牌；方形、胶囊或模式 A 的参考值均可合理不同。检查嵌套边缘和整体比例，不把圆角大小变成通用评分项。

### F.7 解释型界面与可探索内容【归纳】

网站本就包含聊天、教学、比较或参数探索，且交互有助于理解时，让用户改参数、切状态、比较结果，并说明输入与结果的关系。保留文本说明和可访问的静态结果；展示真实过程，不加假进度或纯装饰等待。

这是呈现选择，不要求每次聊天都生成 UI，也不为普通网站自动增加聊天系统。简单事实与一次操作可直接文字说明。自定义渲染按 [特殊渲染](../../特殊渲染.md) 选必要能力。本项及圆角阶梯是用户经验的归纳，不标成浏览器 API 或外部研究结论。
