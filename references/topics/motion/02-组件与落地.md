# 交互动效：组件与落地

[专题索引](../../交互动效.md) · [先读使用边界](00-使用边界.md)。命令与代码路径仍以技能根目录为基准。

## C. 交互清单（按要求优先列新鲜、好玩、当代的做法）

**按压 / 微反馈（弹性）**
- **按压回弹**：`:active` 时 scale 0.97，松手由 transition 回弹；想要更“活”就让松手走弹簧（bounce 0.1–0.3）。适用于一切可按的元素。实现：CSS 或 Motion。（Emil 7 tips / SKILL.md）
- **长按删除 / 长按确认**：一层彩色遮罩从 `clip-path: inset(0 100% 0 0)` 用 2s linear 填满，松手 200ms 弹回，同时按钮 scale 0.97。有手感，又防误操作。全程 GPU。（Emil SKILL.md）
- **Tab 颜色无缝切换**：复制一份“激活态” tab 列表，用 clip-path 只露出当前项，切换时动画 clip；效果比逐个过渡颜色干净。（Emil SKILL.md）
- **状态变形 + 模糊**：按钮文字从“复制”变成“已复制”时交叉淡化，加 2px blur，配合 scale 0.97。（Emil 7 tips）
- **可把玩（fidgetability）**：让用户愿意反复拨弄的小交互，比如 AirPods 盒盖。适合低频、偏情绪的组件。（Rauno）
- **庆祝型次要动作**：例如完成任务后偶尔飞过一只独角兽（Asana）、点“喜欢”时爱心跳一下（Gap）。前提是低频，并且附带撤销。（NN/g 微交互；IxDF secondary action）

**光标 / hover（好玩的反应）**
- **磁吸按钮**：按钮被指针“吸”过去，内部元素用不同位移产生视差，还可以加描边或阴影的附加动画。源自 Cuberto。https://tympanus.net/codrops/2020/08/05/magnetic-buttons ，代码 https://github.com/codrops/MagneticButtons
- **自定义光标**：小圆点加一个会“吸附”导航项、带噪声抖动的圆环（Paper.js + Simplex Noise）。https://tympanus.net/codrops/2019/01/31/custom-cursor-effects 。注意：只在 `@media (hover:hover) and (pointer:fine)` 下启用（Emil SKILL.md 检查表），并且必须保留原生光标的可用性【归纳】。
- **跟随鼠标的倾斜 / 位移**：把鼠标坐标交给 useSpring 处理，不要直接绑定，否则显得机械。仅限装饰用途。（Emil SKILL.md）
- **图片 hover 变形（WebGL 位移图）**：用一张 displacement 图把两张图扭曲后再交叉淡化，three.js 实现。https://tympanus.net/codrops/2018/04/10/webgl-distortion-hover-effects 。更进阶的有速度感知的曲面扭曲、RGB 分离、图片拖尾：https://tympanus.net/codrops/2019/10/21/how-to-create-motion-hover-effects-with-image-distortions-using-three-js （只读到搜索摘要，未读全文）
- **clip-path 双图揭示**：clip-path 配合 `steps()` 缓动，做出阶梯式 / 故障风的揭示，可叠加 filter 反相。https://tympanus.net/codrops/2023/03/01/double-image-hover-effects-with-clip-path-animations
- **Popover 从触发点长出来**：设置 `transform-origin` 为触发器位置（`var(--transform-origin)`），弹窗本身保持居中。（Emil 7 tips）

**滚动（有新意的叙事）**
- **原生滚动驱动**：`animation-timeline: scroll()` 或 `view()`，配合 `animation-range` 控制区间，不需要 JS。https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Scroll-driven_animations 。可以配合 `linear()` 弹簧曲线，让元素进入视口时带一点回弹（Josh Comeau【从业者观点】https://www.joshwcomeau.com/animation/scroll-driven-animations/ ，未读全文）。
- **Sticky 叙事 / 钉住**：GSAP ScrollTrigger 的 `pin` 在两个滚动位置之间钉住元素；`scrub:true` 把动画直接绑在滚动条上，`scrub:1` 表示 1 秒追平；`snap` 吸附到时间线 label；`toggleActions` 默认 "play none none none"；开发阶段用 `markers`。https://gsap.com/docs/v3/Plugins/ScrollTrigger/
- **滚动揭示图片**：从 `clip-path: inset(0 0 100% 0)` 到 `inset(0)`，入视口时播放一次（`useInView({once:true, margin:"-100px"})`）。（Emil SKILL.md）
- **平滑滚动 Lenis**：基于原生滚动，所以 sticky、锚点、无障碍都照常可用；可驱动 WebGL 场景 / ScrollTrigger（`lenis.on('scroll', ScrollTrigger.update)`，并设 `gsap.ticker.lagSmoothing(0)`）。限制：不支持 CSS scroll-snap；Safari 上锁 60fps、低电量模式锁 30fps；iframe 上会失效。（Lenis README）
- **滚动地标**（Rauno 原型）：双击滚动条记下位置，方便长文来回跳。思路新、实用。

**页面 / 视图切换（共享元素）**
- **View Transitions**：同文档用 `document.startViewTransition(cb)`（Chrome 111+、Safari 18、Firefox 144）；跨文档在两页都写 `@view-transition { navigation: auto; }`（Chrome 126+、Safari 18.2，Firefox 尚不支持）。默认效果是交叉淡化；给元素设 `view-transition-name`，就能做缩略图到大图的形变（group 会过渡位置、宽高）；用 `view-transition-class` 批量写样式。https://developer.chrome.com/docs/web-platform/view-transitions 、/same-document
- **Motion 布局动画**：`layout` 自动动画尺寸和位置变化，比如 justify-content 切换、列表重排；`layoutId` 做共享元素，比如下划线跟着 tab 跑、按钮变形成弹窗，配合 `AnimatePresence`。内部都用 transform 实现。https://motion.dev/docs/react-layout-animations
- **Dynamic Island 式流体变形**：形状连续变化，并保留手势的速度和角度。（Rauno；Emil 课程演练）

**加载 / 状态**
- **入场用 `@starting-style`**：不需要 JS mount 标记；toast 一类快速连发的元素用 transition（可打断），不要用 keyframes。（Emil SKILL.md）
- **转圈要转得快**：转得快的 spinner 让人觉得加载更快。（Emil）进度指示器、待命态（iOS 图标抖动）都属于微交互。（NN/g 微交互）
- **骨架屏 / 乐观 UI**：本次没有读到权威页面，见 F。

**文字**
- **拆分 / 打乱 / 揭示（split、scramble、reveal）**：Codrops 的相关文章链接已 404，本次没有可引用的一手实现；只能参考上面的原则（每个元素间隔 30–80ms，只播放一次，不能阻塞阅读）【归纳】。

**通用实现与无障碍**
- reduced-motion 时：用 `@media (prefers-reduced-motion: reduce)` 把位移换成淡入淡出（Emil Great Animations 示例）；也可以关掉 `::view-transition-*` 的动画（Chrome 文档）。
- hover 动画包在 `@media (hover:hover) and (pointer:fine)` 里（Emil SKILL.md）。

## D. 反例：“AI 味” 与老套动效

**有来源的**
- 每个 section 滚动时淡入上滑，用户被迫“等文字加载”。NN/g 的建议：只用在次要内容上；只播放一次；任务型网站（医疗、金融、B2B）慎用。https://www.nngroup.com/articles/scroll-animations/
- 视差滚动：用户扫读得快，常常错过内容；动画还没触发时只看到空白；难以控制。如果非用不可，要克制，并把控制权交给用户。https://www.nngroup.com/articles/parallax-usability/
- 自动前进的轮播、滚动劫持：属于可访问性风险（NN/g animation-duration）。
- 从 `scale(0)` 弹出来；UI 用 ease-in；`transition: all`；popover 从中心缩放；让键盘/高频操作等待装饰动画；短小高频反馈无依据地拖长；进退场一样快；所有元素同时出现（或者反过来，stagger 太长）。（Emil SKILL.md检查表的应用判断；键盘例外按A4/J3，体量与距离按J2，不把300ms当所有动画的硬上限。）
- 无意义、高频的“惊喜”动效，第二天就会变得烦人（Emil You Don't Need Animations；Rauno）。
- 过度夸张（IxDF：夸张过头会让人烦）。
- 线性匀速运动显得机械（NN/g）。

**老套 / 过时清单【归纳 + 用户偏好，未必有出处】**
- 通用的 bounce / 弹跳入场，比如 animate.css 式的 bounceIn，以及到处 overshoot
- 慢悠悠的转圈 loader、全屏 loading 遮罩
- 自动轮播的 Hero 幻灯片
- 每块都 fade-up 的 AOS 式滚动入场
- 大面积视差背景
- 鼠标拖尾的彩色粒子、光标完全替代原生光标
- 无限循环的抖动 / 脉冲 CTA
- 全站 `transition: all .3s ease`

## E. 必做清单【归纳】
1. 所有可按元素都有 `:active` 按压缩放（0.97，160ms ease-out）和 `:focus-visible` 样式。
2. hover 反馈 ≤200ms，只在 hover 设备上启用；同组 tooltip 第一次之后瞬间出现。
3. 弹窗、抽屉、下拉都有进出场：ease-out，150–300ms，从触发点长出来，退出比进入快。
4. 页面或视图切换至少做一个共享元素过渡（View Transitions 或 layoutId），并保证不支持时能正常降级。
5. 签名交互（可选，按调性决定）：整个网站可以有一个让人记住的、只属于这个品牌的交互，比如咖啡品牌的“倒咖啡”进度条、作品集的磁吸光标。不是每页都要，调性严肃的网站可以没有。有就只放 1 处，且在低频位置。
6. 装饰性的滚动入场优先用于次要内容、通常只播一次，正文不等动画。采用[滚动叙事](../../滚动叙事.md)时，承载核心信息的场景按分镜由进度或章节控制，支持倒滚、快滚和跳转；不受“只播一次”限制，但必须保持可读与可降级。
7. 异步操作都有即时状态：按钮内 loading，完成后变形成“已完成”。
8. 视觉移动/缩放优先transform、显隐优先opacity；真实布局变化及其他必要属性按K节判断，不作一律禁用；全局支持 `prefers-reduced-motion`。
9. 统一定义 motion token：2–3 条缓动曲线、4 档时长、1 组弹簧参数，全站共用。

## G. 落地方式

1. 开工先建 motion 令牌：直接复制 `templates/motion-tokens.css`，全站只用这里的缓动和时长。
2. 设计说明（步骤8）里写一张“动效表”：每个交互写 触发 → 效果 → 时长/缓动 → reduced-motion 下怎么降级。没写进表的动效不准做。
3. 每个页面满足 E 节第 1～4、6～9 条；第 5 条签名交互按调性决定要不要，整站最多 1 处。
4. 先按下面 H 节确定调性档位，再从 C 节挑交互。同一个网站只用一个档位的参数。
5. 评审时，动效和微交互两个维度按 A～E 节打分；命中 D 节任一条，该维度不得判“持平”以上，除非设计说明写明理由。
6. 验证：页面阶段用 Chrome DevTools MCP 的性能面板录一次交互，确认没有 layout/paint 抖动；`npm run gate` 里 reduced-motion 截图必须正常。

## H. 按网站调性选动效档位

依据：Emil Kowalski 的建议是动效要和品牌气质一致，Sonner 故意用稍慢的时长和 `ease` 显得优雅，俏皮组件可以多一点弹，专业仪表盘要干脆、快（https://github.com/emilkowalski/skills/blob/main/skills/emil-design-eng/SKILL.md ）。下表的具体分档是本技能的归纳。

| 档位 | 适合 | 时长 | 缓动 / 弹簧 | 可选的特色交互 | 不要 |
|---|---|---|---|---|---|
| 干脆 | 工具、后台、金融、B2B | 偏短：按压 100ms，弹层 150～200ms | ease-out，不弹 | 无签名交互；状态变形、骨架屏做细 | 滚动揭示、光标特效、弹跳 |
| 克制优雅 | 奢侈品、建筑、编辑类、高端服务 | 偏长：弹层 250～350ms，图片揭示 600ms 左右 | `ease` 或 ease-in-out，不弹 | clip-path 图片揭示、跨页共享元素过渡、平滑滚动 | 弹簧回弹、磁吸、彩色光标 |
| 有活力 | 消费品牌、餐饮、活动、潮流 | 中等：按压 160ms，弹层 200～250ms | 弹簧 bounce 0.15～0.25 | 磁吸 CTA、弹簧跟随、滚动叙事 | 高频操作加弹跳 |
| 实验 | 作品集、创意机构、活动专题 | 可以更长的编排时刻 | 弹簧 bounce 0.2～0.3，可用 WebGL | 自定义光标、图片变形、钉住式叙事 | 牺牲正文可读性和加载速度 |

选档写进设计说明，评审 Agent 按所选档位判断动效是否到位：干脆档没有签名交互不扣分，有活力档整站毫无弹性要扣分。
