# 反推任务输入

未填写的选填项按默认处理，不会因选填缺项再次询问。
默认直接给网址即可：专用子 Agent `website_prompt_reverser` 自己浏览、侦察多级拓扑与全局壳、交互取证并反推出 100% 忠实于参考站的《原站基准制作提示词》（Base Prompt）；用户若有新主题、配色或定制需求，在 Base Prompt 通过门禁后的**阶段 3.5** 由专属改写子 Agent `website_prompt_adapter` 统一执行定向改写，**不传给反推子 Agent**。
平台名（如 Shopify）或行业名不等于具体网址；此时只补问一次具体参考网址，不自行选官网、商店、本地旧站或当前浏览器随手停留页。

## 选填｜页面范围与执行分支
- 页面深度模式（`page_scope_mode`）：
  - `multi_level_l1_l2`（默认）：首页 + 主导航可达的 L1 一级主页面 + L2 二级子页面/详情页代表模板 + 共享全局壳 `SHELL-xx` + 跨页转场 `PT-xx`
  - `single_page`：仅当用户明确只要首页 / 单页
- 必须覆盖的指定路由（`pages_hint`）：[选填 URL 列表，如作品列表、指定详情页]
- 取证模板预算（`sampling_budget`）：[默认：L1 ≤6 个模板，L2 ≤3 个模板]
- 执行分支（`branch`）：
  - `prompt_only`（默认）：仅反推并交付提示词与分层生图方案（有定制时交付双份）
  - `prompt_to_site`（提示词复刻网站）：Base 门禁与阶段 3.5 定制改写完成后，由主 Agent 按执行版提示词自建，或派发 1–4 个构建子 Agent 并行生图并建站
- 若为 `prompt_to_site`，偏好建站方式：[自动判定 S1/S2（默认） / 指定由主 Agent 自建 / 指定派发构建子 Agent]

## 选填｜定制需求（阶段 3.5 统一交由 website_prompt_adapter 改写，不传给反推子 Agent）
- 新主题 / 品牌 / 受众（`new_theme`）：[不填则 1:1 结构复刻，品牌与文案占位]
- 新配色需求（`new_palette`）：[1–5 个目标 HEX 或色彩描述；阶段 3.5 按 OKLCH ΔL/ΔC 推导色阶与 ≥4.5:1 对比度矩阵，并同步 Shader/生图]
- 文案语言切换（`copy_language`）：[如英文站改中文，触发 §3.3 中文字体与字距/行高补偿]
- 模块增删与其他具体需求（`custom_requirements`）：[文案替换、区块增删合并、技术栈指定等]
