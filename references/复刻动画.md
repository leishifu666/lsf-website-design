# I 复刻动画

从用户指定的网页区块、交互、录屏、GIF、Lottie 或其他动画文件，在原项目复现运动，再用相同输入采集成品比较。实现与取证代码来自内置 [reanimate](../vendor/reanimate/SKILL.md) 的固定版本；本页是适配 LSF 范围与工作方式的入口。上游的绝对确定性说法以实际重复采样为准。

## 范围与保真目标

先查看目标、项目组件和现有动效库，在 `.reanimate/<目标名>/spec.md` 简短记录来源及选择器/时间段、代码落点、保真目标。复用[规格模板](../templates/动画复刻规格.md)。明确的输入直接使用；只有核心范围含糊时才问。不自动启动网站 `begin`、五站调研、文案生成、生图、三预览或独立整站评分。

| 用户要求 | 保真目标 | 比较内容 |
|---|---|---|
| 复刻动画、相同交互、像这样动 | motion-faithful | 触发、先后、交错、起止与缓动、相对运动距离、布局比例及机制；保留本项目的内容与品牌 |
| 完全一样、1:1、像素级 | pixel-faithful | 上述内容，加字体、布局、颜色、圆角、阴影、素材和逐帧图像；明确修改项单列 |
| 复刻并换内容/增加功能 | mixed | 按前两档核对保留部分；标出新内容对布局、运动及操作的影响 |

不能把 A 风格参考降成 motion-faithful：A 仍须保留主参考的构图、按钮、配色与核心表现，主题替换按对应区域解释。

## 执行

1. **取证。** 先读[采集与对照命令](动画取证与逐帧对照.md)。网页先实际操作确认加载及目标，再采固定视口、触发、轨迹、时长、帧率的 reference。Canvas/Three.js/WebGL 加 GPU 追踪和资源下载，先查看 `gl/summary.md`、JS、shader、模型和动态通道。视频/GIF 先查看时段与裁切；只有视频时无法取得原站 shader，不编造内部实现。
2. **规格。** 看完目标时段的连续帧拼图，每个运动对象/属性一行，保留静止层、遮罩、transform-origin、溢出、离开/反向/重复。直接读取、实测、拟合和未知分开。关键未知先补采，不凭初尾两帧猜缓动。细节按[上游分析方法](../vendor/reanimate/references/analysis.md)选读。
3. **实现。** 在原项目用现有组件和库；必须新增依赖时说明它承担的效果。Canvas 场景从真实 shader、合成 pass、材质、相机、几何或动画轨建立机制。保留已观测的效果，不套通用 fade-up，也不因通用 hover 偏好删除源效果。按[上游实现参考](../vendor/reanimate/references/implementation.md)选读相关栈；不可读的内部状态按可见行为复现并写明推断。
4. **验证。** 相同采集条件录 clone-01，生成 compare、连续帧并排和关键属性/GPU 通道比较。真实时钟检查正常交互、停止、反向和打断；虚拟时钟用于可重复的逐帧分析。适用的键盘、触屏与减动效按当前组件范围验证，不机械扩成整页三尺寸。
5. **修正与交付。** 修证据指出的最大差异，再采新目录。达到目标即停；同一问题两次无进展换调查方法，最多五轮后列明尚未达到的行与原因，不自行放宽标准。交付实际代码、触发方式、关键时序/轨迹差值和对照图；不能用报告已生成或退出码 0 表示复刻通过。

## 比较口径

上游的 ±80 ms 时序、5% 轨迹范围误差、像素均差 ≤2% 是**默认诊断基准**，受帧率、字体、裁切和原站波动影响；先确认有效采集条件，不把它们称为任意动画通用的精度保证。像素级还需查最差帧、静止帧和逐行规格；仅全图平均数可能漏掉小而重要的目标。

同源重复采样先检验稳定性。持续粒子/噪声可同时看原始与模糊差值，模糊不能掩盖缺失图层和错误转场。截图变化量可能受主题与文字影响，单一 activity 曲线不能证明全部动效等价。比较方法与限制见[公共取证说明](动画取证与逐帧对照.md)，详细报告字段见[上游验证说明](../vendor/reanimate/references/verify.md)。
