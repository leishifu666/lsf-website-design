# A直接制作与三预览分流，C原创方向确认

用户2026-11-02最新确认：普通风格参考默认直接制作一套；用户想比较时才先做三个预览。A的三位构建者使用同一份完整提示词、同一个主题与同一个主参考网址，不预先分配三种设计任务。本条覆盖旧“A/C一律先三版”、A各用不同参考、A差异任务卡及硬性差异数量要求。只分析、提示词、评审或更新技能不启动网页制作。

## 1. 先分流，明确要一套还是三个预览

| 用户意图 | 执行路径 |
|---|---|
| 给参考网址，说“按这个做”“直接做”，或选择只做1套 | 由当前对话的主Agent直接制作一套网站；不另开用户聊天、不另派构建Agent、不插入三版比较与选择等待 |
| 明确说“先看看三个”“比较方案”“让我选” | 先做三个高质量关键片段预览，用户确认后只展开一个方向 |
| 开始时确实需要展示制作方式选择 | 只说明“直接制作1套”与“先看3个预览再选”；已表达清楚的直接分流，不重复询问或展示模式菜单 |
| 明确要原创方向探索C | 保留C的三个产品相关方向与方法筛选；用户明确要直接出一套时仍以本次范围为准，不强加三版 |
| 子任务范围为“完成一个方向预览” | 仅完成一个预览，不再选择制作方式、不递归派发三个预览 |

选择只做一套时，无论A参考或C原创，均由当前对话主Agent直接制作；只有用户本次另行明确要求构建并行时才按该授权处理，旧的多构建能力或历史授权不默认触发。独立文案审核与视觉评审职责继续保留。

直接制作与三预览是交付方式，不自动改变A参考、C原创等工作模式。用户中途改变选择时按最新意图切换，保留已有有效内容与证据。

## 2. A三预览：完全相同的提示词与参考

使用[风格参考统一提示词](../templates/风格参考统一提示词.md)，只填用户主题、完整网址与本次范围。三份的范围均为“完成一个方向预览”，正文、主题和网址逐字一致；已有的共同用户约束也必须一致提供。不给某一位追加特别的构图、沟通目标、素材、交互、种子或技术路线，也不通过附件与暗示变相分配不同设计任务。

三位构建者各自实际浏览、操作同一主参考，按技能高精度参考它的外观、交互及真实实现机制。设计与实施判断由各自独立完成，主Agent不预先指定三个差异方向。结果可以接近，如实展示各自完成情况；不能为了凑差异偏离参考，也不把近似结果夸成三种新风格。

用户没有给网址时，主Agent先按A的实际研究规则选择一个合适主参考，再把同一网址填入三份提示词。用户明确只要找多个参考网站时进入D，不把A的三个预览变成三个不同参考网站。

C原创三方向继续按[原创构图方法库](原创构图方法库.md)形成产品相关记忆点；不调用A模板、不把A的同一参考规则误用于原创抽签。此项不改变用户已确认的原创方法或评审预算。

## 3. 在当前主对话汇总，独立构建

本节独立构建仅适用于已选择的三预览路径。用户在当前主对话查看与反馈，不需要另开三个用户聊天。已有多构建授权且宿主支持时，优先由三个独立子Agent各完成一个A预览；它们只接收同一份设计提示词与共同材料，完成前不看其他预览的草稿、截图或代码。不要把其他版结果复制给下一位当作起点。

主Agent管理共享基础、入口与整合。统一的文件归属规则按各Agent自身任务名对应到原项目内的独立预览目录，向所有构建者提供同一规则；不得改共享令牌、主路由或其他预览。告知它们不独占代码库，保留他人改动。不创建worktree，不把文件隔离变成不同设计提示词。

宿主不支持独立上下文、授权不足或并发不可用时，保留相同提示词与范围，按可用方式顺序制作，并如实说明执行方式；不能冒称已经由三个独立Agent完成。本文件不自动授权外发资料或创建用户聊天。

## 4. 每个预览的完成度

每版先认真完成最能代表参考体验的一个关键片段，配齐判断它所需的标题、内容、主体、行动入口与代表性交互；不是同时制作三套完整网站。以下为共同质量要求，不为三个Agent分别指定设计方案：

- 使用真实主题与已确认文案，未知事实标占位；预览临时文字不冒称Gemini定稿，正式文案继续按[文案审核](文案审核.md)执行。
- 新图片实际调用Codex内置生图，透明底与固定提示词结尾按[氛围图片](氛围图片.md)执行，不另加图片一致性流程。
- 按[组件源码复用](组件书签与源码复用.md)取得并使用适用开源实现；每个实际制作的预览网页仍满足既有五项不同适用组件/动效要求，不为凑数堆控件。Taste基础的能力边界见[产品参考与复用来源](产品参考与复用来源.md)。
- 核心交互、模型和渲染必须按真实机制做成可运行体验，鼠标操作有反馈，兼顾触屏、键盘与减少动态效果；UI图标只用开源库，禁用按钮hover上浮与hover带动图标运动。
- 实际打开每个预览，在375/768/1440检查并截图，核对标题、边距、主体裁切、对比度、焦点和相关状态。参考与实现同视口、同状态对照，不能用选择页截图代替各预览的检查。

默认给可打开页面、截图和访问入口。用户明确只要静态方向时可交图，但说明未实现的交互。主Agent保留开发自查，成品仍由独立视觉Agent取证与评审；预览不新增独立评分轮次。

## 5. 用户确认与继续

仅在用户选择了三预览路径时，交付甲/乙/丙入口与实际完成情况，等待用户选定或明确授权代选；期间可修复预览缺陷。直接制作路径不新增这道选择。

用户认可某版就沿其继续，三版全不满意时先根据反馈确定调整方向，再补充必要研究并制作新预览，直到确认。新一批A预览仍使用同一份更新后的提示词与相同参考，不分别暗设方向；用户只要求修改其中一版时按该次范围处理，不重开三版。反馈不足时只问关键问题，不无限盲猜，也不把首批三个当作停止服务的上限。

方向选择不等于独立视觉验收，也不消耗或重置成品两次调用、一批修改的预算。选定后将参考、规则和核心机制归并到DESIGN.md，只展开一个方向；后续区块同样认真制作。
