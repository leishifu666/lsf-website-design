# 视觉评审共用约束

本文件只包含成品评审必需的共享规则，替代审查包中整份建站入口；完整任务规则仍以用户要求、项目AGENTS、DESIGN、目标卡和组件合同为准，不裁剪项目规则正文。通过[审查规则索引](审查规则索引.md)按具体问题补读，不一次加载整套制作流程。

- 核对真实构图、排版、素材层次、产品辨识、渲染机制和动效；不能仅看文件存在、库已导入或静态相似就称实现完成。
- 新图片使用Codex内置生图；用户要求GPT Image 2.5，工具未给型号时不伪称已锁定。透明主体检查真实alpha。每条生成、编辑和变体提示词以“画面干净通透，材质完整自然，纹理平滑统一，主体清晰，避免过度锐化、色斑、噪点、碎纹、崩坏和畸变。”结束。
- UI图标只用开源图标库，禁止手写SVG图标；SVG立体示意允许，不能借此冒充真实三维。实际组件/动效须有适用源码来源，不能用只引库或重复实例凑数；来源核查另作实现记录，不增评分维度。
- 禁用按钮hover整体上浮和hover带动图标运动。真实点击与hover区分；动效看实际时序、中间态和反馈，保留用户选择的丰富场景与适合的GSAP编排。模型/图形场景核对鼠标反馈、触屏/键盘替代及减少动态效果。
- 文案有无冗余与模块有无价值分别判断。不能因删短文字而裁掉承担产品、导航、交互或叙事作用的区块、素材与动画。
- 独立视觉Agent用Ego Lite获取实际样式、几何和375/768/1440截图，核对边距、异常空白、首屏标题及相关状态；测量是证据，不机械判审美。优先Gemini/Claude；均不可用才用当前模型独立子Agent，身份和查看能力如实记录。
- 只按现有五维与三项视觉约束评审，工程数据不占设计分，不为性能降低场景。最多两次调用、一批修改，首审达标即止，失败/超时共用预算。三版风格选择属于前期用户确认，不自动增加评分次数；只评审时不发起预览制作。
