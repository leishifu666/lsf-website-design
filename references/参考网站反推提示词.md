# 模式F：参考网站反推建站提示词

## 触发与边界

用户要求“根据参考网站反推提示词”“写完整建站提示词”“提取参考的所有设计规格给另一个AI制作”时进入模式F；用户明确只要提示词时优先于模式B/A的直接制作。用户直接要做网站仍走原模式，不强制先加本模式。

用户于2026-10-19直接要求将所附角色、输入模板和输出模板制作成子Agent并作为本模式调用。此委派授权仅适用于本角色的参考研究和提示词生成；不代替网站实施、发布、付费、登录或其他代理授权。只更新本技能不会自动研究当前浏览器页面；ambient URL不是用户选定的参考站。

## 主Agent如何调用

1. **默认直接转交用户的具体网址**，沿用已知范围、主题和必要约束即可；子Agent自己打开网站、浏览完整页面、操作交互、检查动态与响应式并反推，主Agent不先做网站研究或要求用户补截图。只有用户主动提供图片/视频/录屏时才代为转交；可作补充，也支持没有网址时的附件输入。选填项不要求全部填写。默认单页及必要关联状态、高保真、只生成提示词，技术栈依项目或明确标建议。Shopify等平台名不能唯一确定网站，没有网址或可用附件时只问一次具体参考网址，不能自行选平台官网、商店、本地旧站或环境地址。已有网址就直接访问，不通过搜索另选参考；仅用户明确帮找参考时转模式D。
2. 启动一个专用子Agent：当前可用角色中有 `website_prompt_reverser` 就按其实际工具接口调用；若当前会话尚未暴露新角色，使用新 `default` 子Agent，并在任务开头要求完整读取角色文件和两份模板后按同一角色执行。不能把 `task_name` 当作已经加载原生角色的证据，也不能尝试工具未提供的类型。无委派能力时先整理材料，说明具体限制，不冒称已调用。
3. 传入绝对 `skill_root`、本次任务边界和必要材料；指定仅研究、不改网站；主Agent保存用户上下文并收回结果。无需传无关历史、整个项目或凭据。
4. 子Agent按证据研究、转译、检查并回传：不超过15行研究记录 + 一段完整、自包含的12节建站提示词。根据参考主动判断需要哪些生图素材，附透明底单体/环境背景的选择、分层与逐项完整生图提示词，每条以用户固定质量句结束，规范见[氛围图片](氛围图片.md)。默认仅交方案不实际生图。仅指定路径时才落盘该文档。
5. 主Agent核对范围、证据标签、信息完整性、禁用hover、表现技术与核心机制合同及源码/许可声明；GSAP用于适合的编排，不覆盖参考核心渲染与时间线。按[表现技术选择](特殊渲染.md#01-所有模式先选表现技术再制作)检查是否明确了真实渲染、资源、驱动与合成，避免只写“加高级动效”或默认平面替代；发现具体遗漏交给同一子Agent补充，不自行把未知改成实测。
6. 提示词生成完成即交付。用户明确还要实现（含输入选“是”）才由主Agent沿用研究结果转入适当的网站制作模式，无需重复取证。只要提示词时不运行Gemini文案、workflow-check制作登记或网站85分评审，不生成方向预览和网站代码。

### 通用子Agent入口的交接示例

```text
作为 website_prompt_reverser 执行本次研究任务。
skill_root：<实际安装的lsf-website-design绝对路径>
完整读取 agents/website-prompt-reverser.md、templates/反推任务输入.md、templates/网站制作提示词.md。
用户输入：<已给的URL/截图/录屏、范围、主题、内容、技术栈及其他限制>
默认组件索引：<skill_root>/references/component-bookmarks.json
只研究并交回完整建站提示词；不得修改网站、安装、提交、外发或递归委派。
输出：研究记录 + 完整提示词；<仅用户/主Agent要求落盘时给绝对输出路径>。
```

## 完成判定

参考页面、宽度、状态和观察方式如实记录；未知与建议明确；全局令牌、逐区块结构、组件状态、动画时间线、响应式、素材/源码、实现约束、禁用项、待执行验收和未确认信息齐全。仅静态截图可以完成有证据的静态反推，动画用未知/建议表达，不需要为了缺少动态证据停止整个任务。

用户提供角色全文保留在专用角色文件，已适配本机工具边界、默认书签来源和选填不追问规则；角色不是外部Claude模型调用。模型继承父会话，不自动改为Claude或Gemini。
