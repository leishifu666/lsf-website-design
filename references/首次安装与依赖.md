# 首次安装：三个必备组件

**仅在用户明确安装本技能、首次安装完成后的交接中触发。** 已安装后的日常建站、分析、修改技能不重复推销、确认或安装，不把第一次调用误当第一次安装。本次若是安装请求，即使用户没逐项点名，也自动介绍以下三项并检查缺项；可读取现有安装记录，避免多次提醒。

| 必备组件 | 准确名称与用途 | 官方来源 |
|---|---|---|
| 多模型调度skill | `lsf-ai-agent`，网页文案与Gemini/Claude视觉评审交接 | [GitHub仓库](https://github.com/leishifu666/lsf-ai-agent) |
| 浏览器skill | `ego-browser`，即这里所说的browser skill，提供Ego Lite操作规则 | [官方技能](https://github.com/citrolabs/ego-lite/tree/main/skills/ego-browser) |
| 浏览器应用 | Ego Lite，提供真实浏览器与`ego-browser`命令 | [免费下载](https://lite.ego.app/)、[官方仓库](https://github.com/citrolabs/ego-lite) |

三个组件本身免费提供；模型服务的账号、额度或订阅遵循各自条件，不把免费组件说成免费无限调用所有模型。官方说明Ego Lite安装后会加入ego-browser skill，仍核对技能文件与命令是否实际可用，避免重复安装。

## 安装交接

1. 根据宿主技能目录检查两项SKILL.md是否可读、`ego-browser`命令是否可用。只检查安装，不擅自登录模型、导入浏览数据、配置API或升级。
2. 首次安装时，无论是否缺项，都简短给出三项准确名称、上述可点击链接和免费说明；有缺项时直接说明缺什么，并问一次是否让Agent协助安装。用户的原话已明确包含安装这些依赖时，直接在授权范围执行可逆安装，不再次索要许可。
3. `lsf-ai-agent`从上述GitHub官方仓库按其README安装到实际技能目录，保留相对结构；已有本地定制不可覆盖。浏览器skill可按Ego官方README用`npx skills add citrolabs/ego-lite`或随应用安装，核对当前文档，不编造其他browser skill的仓库。
4. Ego Lite应用按[官方安装规则](https://github.com/citrolabs/ego-lite/blob/main/skills/ego-browser/references/install.md)与实际平台执行。Windows下载官方安装器，GUI首次引导、登录和系统确认由用户完成；不冒称已自动完成。完成后执行`ego-browser skill`及实际连接检查。
5. 在安装交接/安装器已有回执里记录已说明、已安装或待用户处理的状态；有记录则不重复提醒，不为此新建全局Hook或后台任务。缺项时不声称“完整工作流已就绪”，可继续不依赖该组件的阅读与分析。

核对日期：2026-11-02。本文件是安装场景的使用契约，不能让一个尚未运行的SKILL.md自动执行系统安装；由处理安装请求的Agent读取并执行。
