# 模式A 脚本实测记录（2026-10-19）

环境：Debian 13 arm64 沙箱，Chromium 155（Debian 包，`CHROME_PATH` 指定），Playwright 1.5x，Node 22。参考站只做取证测试，没有做完整还原页面。

## 1. linear.app（无 GSAP、无 WebGL，CSS 过渡为主）
- extract-tokens：117 个样式表（大多在 static.linear.app CDN 上，旧版脚本读不到）、670 个声明变量、Inter Variable / Berkeley Mono 两个字体。正文 15px/24px、字距 -0.165px；底色 rgb(8,9,10)。
- extract-motion：识别到 View Transitions；28 个交互。主按钮 Get started：hover 底色 rgb(229,229,230)→rgb(255,255,255)，按下 scale 0.97；Contact sales 同样 0.97。旧版脚本按 DOM 顺序取前 15 个，前面全是导航和产品截图里的控件，这两个主按钮测不到。
- extract-components：28 个变体，按显眼度排序后前两名是 Get started、Contact sales（44px 高、左右 20px、圆角 9999px、16px/510）；区块 128px 上下内边距。

## 2. gsap.com（GSAP + ScrollTrigger）
- 库：gsap 3.15.0、ScrollTrigger、SplitText。
- 运行时读到 30 个 ScrollTrigger，其中 `home-animate__wrapper`：pin、scrub 1、end +=3000px；其余多为 start "top 90%" / "top 70%" 的进场。
- 平滑滚动：滚轮 400px 后 60ms 位移 0、960ms 位移 400 → 有平滑滚动。

## 3. lenis.darkroom.engineering（Lenis + three.js + WebGL）
- html class 含 `lenis`；three.js r182；canvas 探针记录到 1 个 webgl2 上下文（powerPreference high-performance、antialias），6 段着色器源码，340 次 rAF。
- 首次实测平滑滚动判成“否”，原因是首屏有加载锁、第一下滚轮页面没动。改成页面开始移动后再测，重跑结果：60ms 位移 233、960ms 位移 400 → 有平滑滚动。
- 新增的伪元素读取在这里生效：3 个链接的 hover 变化发生在 `::after`（scaleY 0→1 的下划线）和 `::before` 上，旧版只读元素本身会判成“无反馈”。
- `locomotive` 被判为有，是源码特征误报（Lenis 源码里出现该字样），以运行时字段为准。

## 4. check-tokens 对账测试
用 linear.app 的规格草稿生成令牌，写两份页面：
- 合规页（只用 tokens.css 变量）：静态 0 项、运行时 0 项。
- 违规页（hex、hsl、oklch、未定义变量、clamp 字号、13px 间距、ease-in、300ms、Tailwind `p-[13px]` `bg-zinc-800` `rounded-[14px]`、React `fontSize: 18`、Motion `duration: 0.6` `ease: [0.4,0,0.2,1]`）：静态报 26 项，运行时报 19 项（另抓到浏览器默认的 h1 外边距 42.88px 和按钮默认字体 Arial）。
- 漏报：`--my-gap: 13px` 这种本地变量，值只要出现在任一类规格里（13px 是规格字号）就放过。用运行时模式兜底。
- `oklch(0.98 0 0)` 换算后与规格色 rgb(247,248,248) 相差 ≤2，按同色放行，这是预期行为。

## 5. Tailwind 4.3.3 编译测试
`tokens.tailwind.css` 清空命名空间后：`bg-zinc-800`、`rounded-lg`、`shadow-md`、`ease-out` 不再生成；`p-4`、`p-[13px]`、`text-[19px]`、`duration-300` 仍生成（交给 check-tokens）。加 `--strict-spacing` 后 `p-4` 不再生成。

## 6. 细节检查与素材处理（同日补充）
- check-transitions：测试页 3 个触发器，生硬弹窗被报“打开瞬间切换”；另测到滚动时 body 底色硬切，加 `transition` 后消失。linear.app：导航菜单打开有过渡，点外部关闭时浮层在 40ms 内已移除、无动画。
- check-text-wrap：「手工拉坯的日 / 用陶瓷工作室」报出「日用」被拆开。
- check-alignment：多 3px 左边距的段落报出。
- extract-media：apple.com/airpods-pro 34 个透明 PNG 抠图主体、20 个满版主视觉。
- process-image pair：合成图 alpha 平均误差 0/255。
