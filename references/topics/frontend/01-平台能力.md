# 前卫设计与前端技巧：平台能力

[专题索引](../../前卫设计与前端技巧.md) · [先读使用边界](00-使用边界.md)。命令与代码路径仍以技能根目录为基准。

## 怎么用这份文件

- 步骤5 发散：每个发散版至少用一项“平台能力”或一个“趋势方向”去实现它的核心想法，并写明为什么这个手段服务于目标，不是为了炫技。
- 步骤6 评审：“独特性与前卫度”打分时，前卫只算“服务目标的新手段”；追趋势但伤害清晰度或可用性的，独特性不加分，可用性扣分。
- 步骤8 实现：广泛可用的能力可直接用于核心布局；新近可用的要写降级；有限支持的只能做渐进增强。

## A. 平台能力（设计用途 / 状态 / 一行用法）
- **滚动驱动动画**：动画进度跟随滚动，不用 JS，可做视差、阅读进度和段落揭示效果 / **有限**（MDN animation-timeline 标注“not Baseline”；webstatus：limited）/ `animation-timeline: view();` — https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/animation-timeline
- **View Transitions（同文档）**：在不同状态之间做形变和共享元素过渡 / **新近可用（2025-10）** / `document.startViewTransition(update)` 配合 `view-transition-name` — https://developer.mozilla.org/en-US/docs/Web/API/Document/startViewTransition
- **View Transitions（跨文档 MPA）**：普通多页网站也能做页面切换动画 / **有限**（MDN @view-transition 标注“not Baseline”）/ `@view-transition{navigation:auto}` — https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@view-transition
- **容器查询与 cq 单位**：组件按自身宽度重排，同一张卡片放进不同栏宽都能自适应 / **广泛可用（2023-02 起）** / `container-type:inline-size; @container (width>700px){}`，字号可用 `cqi` — https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_containment/Container_queries
- **:has()**：可以按“父元素里有什么”或“下一个兄弟是什么”来切换样式 / **广泛可用（2023-12 起）** / `.card:has(img)`；MDN 提醒不要锚定在 body、:root 这类大范围元素上 — https://developer.mozilla.org/en-US/docs/Web/CSS/:has
- **原生 CSS 嵌套**：方便维护，不影响视觉 / **广泛可用（2023-12）** / `.a{ & .b{} }` — https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/Nesting_selector
- **Subgrid**：子元素对齐父网格，跨卡片的标题和正文基线可以齐平，杂志式排版更好做 / **广泛可用**（webstatus，low 2023-09）/ `grid-template-columns: subgrid` — https://api.webstatus.dev/v1/features/subgrid
- **oklch() / color-mix()**：感知均匀的色彩空间，色阶亮度一致，可用广色域 / **广泛可用（2023-05）** / `oklch(70% .15 250)`、`color-mix(in oklch, var(--a) 60%, white)` — https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/oklch
- **相对颜色语法**：从一个品牌色派生 hover、描边、半透明等变体 / **新近可用（2024-09）** / `oklch(from var(--brand) calc(l - .1) c h)` — https://api.webstatus.dev/v1/features/relative-color
- **light-dark()**：一行代码写出明暗两套主题色 / **新近可用（2024-05）** / `color-scheme: light dark; color: light-dark(#111,#eee)` — https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/light-dark
- **可变字体**：字重、字宽、光学尺寸连续可调，可做动态字体效果 / **广泛可用（2018-09）** / `font-variation-settings:"wght" 650` — https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-variation-settings
- **text-wrap: balance / pretty**：标题行长均衡，正文避免孤字 / balance **新近可用（2024-05）**，pretty **有限**（webstatus）/ `h1{text-wrap:balance}` — https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/text-wrap-style
- **@property**：注册有类型的变量，渐变角度和颜色都能直接做动画 / **新近可用（2024-07）** / `@property --a{syntax:'<angle>';inherits:false;initial-value:0deg}` — https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@property
- **锚点定位**：tooltip、菜单直接贴着触发元素定位，不用 JS / **状态不一致**：MDN 显示 anchor-name 新近可用（2026-01）、position-anchor 新近可用（2026-09）；webstatus 的整体特性仍为 limited / `anchor-name:--x; position-anchor:--x` — https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/anchor-name
- **Popover API**：原生浮层，自带顶层显示和轻触关闭 / **新近可用**（属性 2024-04，API 2025-01）/ `<div popover>` 加 `popovertarget` — https://developer.mozilla.org/en-US/docs/Web/API/Popover_API
- **@starting-style**：元素从 display:none 出现时也能做入场过渡 / **新近可用（2024-08）**；注意 transition-behavior 在 MDN 标为“not Baseline” — https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@starting-style
- **interpolate-size / calc-size()**：可以过渡到 height:auto，做手风琴展开 / **非 Baseline，实验性** / `:root{interpolate-size:allow-keywords}` — https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/interpolate-size
- **clamp() 流体排版（Utopia 方法）**：分别定义小屏和大屏两套字号比例（例如 320px 用 1.2、1500px 用 1.333），中间按视口宽度插值，不再依赖断点 / clamp **广泛可用（2020-07）** / `font-size: clamp(1rem, .9rem + .5vw, 1.25rem)` — https://utopia.fyi/blog/designing-with-fluid-type-scales/ ；https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/clamp
- **prefers-reduced-motion**：系统开启减少动态效果时降级动画 / **广泛可用（2020-01）** — https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion

## B. 趋势（只记录来源原话的要点）
- **Figma《Top Web Design Trends for 2026》**：列出 13 条趋势：3D 与沉浸（WebGL、滚动触发）、实验性导航（径向菜单、非线性路径）、高饱和配色（“dopamine design”）、大字号排版、暗色模式（已成标配）、动效与 scrollytelling、游戏化、新拟态、复古未来、极繁、拼贴、新粗野主义/“anti-design”、可持续设计；AI 部分讲的是聊天机器人、语音交互等。注意：这一页没有提到 bento 网格、颗粒噪点或 OKLCH。— https://www.figma.com/resource-library/web-design-trends/
- **Fontfabric《10 Design Trends…2026》**（2025-12，2026-08 更新）：设计圈在反抗“完美 AI 图”，转向“刻意的不完美”（颗粒、手绘、错版、拼贴）；字体本身成为主视觉（动态、可变字重）；生成式和代码驱动的系统；以网格为核心的品牌；超写实 3D；氛围渐变；复古的工艺感；朋克/zine。结论是不要每条趋势都做，而是先决定自己处在“机器精致”和“人手粗糙”之间的哪个位置。— https://www.fontfabric.com/blog/10-design-trends-shaping-the-visual-typographic-landscape-in-2026/
- **Smashing（2026-07，Kat Homan）**，提醒不要盲目追趋势：趋势设计追求的是吸引注意和显得创新；在需要降低认知负担的场景下，新粗野主义、隐藏导航、无标签图标、玻璃拟态、不可跳过的游戏化都可能有害。文章给出五问评估法：认知负荷、情绪匹配、导航可预期、可访问性、参与方式是否有胁迫性。“look has to answer to the moment”；最大的风险是直接照搬 Dribbble 作品。— https://www.smashingmagazine.com/2026/07/designing-distressed-users-mental-health-apps-ui/
- **Smashing 设计栏目列表（摘要层面）**：近期主题有触感 UX（Lottie）、意图驱动的“无界面”交互、AI 界面不应只是文本框、“人们并不想要更多 AI”。— https://next.smashingmagazine.com/category/design

## C. 设计令牌标准
- **W3C DTCG 规范首个稳定版 2025.10**（2025-10-28 发布）：支持主题和多品牌（明暗模式、无障碍变体）；支持 Display P3、OKLCH 及 CSS Color 4 的全部色彩空间；参考实现有 Style Dictionary、Tokens Studio、Terrazzo；Figma、Penpot、Sketch 等已经支持。它是社区组（CG）规范，不是 W3C 正式推荐标准。— https://www.w3.org/community/design-tokens/2025/10/28/design-tokens-specification-reaches-first-stable-version/ ；https://www.designtokens.org/
